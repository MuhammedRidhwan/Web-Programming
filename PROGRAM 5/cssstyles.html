DIFFERENT TYPE OF STYLES

INLINE CSS

  1. Inline CSS is used to style a single HTML element.
  2. It uses the style attribute inside an HTML tag.
  3. It is written directly in the HTML body.
  4. It is useful for applying styles to individual elements.
  5. It does not require a separate CSS file.

INTERNAL CSS

  1. Internal CSS is used to style a single HTML page.
  2. It is written inside the style tag.
  3. The style tag is placed inside the head section.
  4. It uses selectors to apply styles to HTML elements.
  5. It does not require a separate CSS file.

EXTERNAL CSS

  1. External CSS is used to style HTML pages using a separate file.
  2. It is written in a file with the .css extension.
  3. It is connected to HTML using the link tag.
  4. It can be used to style multiple web pages.
  5. It makes HTML code cleaner and easier to maintain.
